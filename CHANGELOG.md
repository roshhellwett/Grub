# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-04-03

### Added
- Initial release of ProjectGRUB
- Interactive CLI menu with 10 menu options
- Theme auto-discovery from themes/ folder
- Pre-flight system checks (10 checks)
- GRUB theme installation with backup
- GRUB theme uninstallation
- Theme validation
- Rollback on installation failure
- Support for 1080p, 2K, and 4K resolutions
- Multi-distro support (Ubuntu, Debian, Arch, Fedora, openSUSE)
- Comprehensive test suite
- Documentation (README, CONTRIBUTING)

### Included Themes
- Vimix
- Xenlism
- Tela
- Dark Matter
- DedSec
